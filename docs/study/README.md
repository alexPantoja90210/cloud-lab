# Per-domain self-assessment

One file per domain and cloud, created when the domain is worked: `identity-azure.md`, `identity-aws.md`, and so on.
Each uses the four-part bar below. A line is only ticked with a link to the evidence.

```
## <domain> on <cloud>

- [ ] Deployed from code        evidence:
- [ ] Broken on purpose once    evidence:
- [ ] Cost shape read from bill evidence:
- [ ] Torn down from code       evidence:

Not done / not understood:
```
